# Radar Vivo

Plataforma inteligente para encontrar oportunidades de negócios utilizando Inteligência Artificial.

## Tecnologias

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## Como executar

```bash
npm install
npm run dev
```

Abra:

http://localhost:3000
